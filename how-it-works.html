About

An idea is something like "when oil jumps, airline stocks fall the next day". The system turns it into a test, runs it on years of data, and keeps only the ideas that survive several checks in a row.

The steps

  1. Write the idea. From people on the team, from AI that reads the news, or from older idea lists.
  2. First screen. A fast test across thousands of companies. Cheap, so most ideas get one.
  3. Second look. The same test on companies the first screen never saw.
  4. Battery check. Harder tests: does it survive earnings dates, simple explanations and shuffled controls?
  5. Confirm on new data. Run once on years the idea was never tuned on (2021). Only then is it a confirmed finding.
  6. Follow it live. Log a prediction each time the event happens, and score it later.

Real, or luck?

Alongside every real test, the system runs luck-only tests on fake or shuffled data. Those can only pass by chance, so they show how often noise gets through. So far it has run 26,164 of them.

At the first screen, real ideas pass 2.7% of the time and luck-only tests 3.2%: no real difference. The battery check only sees ideas that already passed a screen, and there real ideas pass 20.8% against 1.9% for luck. That's where real signals start to show.
